# Complexo Cairbar Schutel Site

Website oficial do Complexo Cairbar Schutel.

## Estrutura do Projeto

- `/admin`: Painel de administração.
- `/api`: Endpoints de API (Vercel/Node.js).
- `/assets`: Recursos estáticos (CSS, Imagens, JS).
- `/financeiro`: Seção de doações e financeiro.
- `/pages`: Páginas de conteúdo do site.

## Tecnologias

- Frontend: HTML/CSS/JavaScript.
- Backend: Node.js + MySQL na HostGator.
- Hospedagem: Vercel / HostGator.

## Configuração

1. Copie o arquivo `.env.example` para `.env` e preencha as variáveis necessárias.
2. Certifique-se de ter o Node.js instalado para rodar o backend localmente, se necessário.
